\# PulseAI



AI Product Intelligence Platform for Data-Driven Teams



\## Overview



PulseAI automatically detects anomalies in product data, investigates root causes, and generates evidence-backed explanations and recommendations.



\## Features



\- 📊 Automatic metric calculation

\- 🔍 Anomaly detection using ML

\- 🔎 Root cause analysis with segment breakdown

\- 💡 AI-generated explanations (Claude API)

\- 💬 Natural language chat interface

\- 📈 Product metrics tracking

\- ⚡ Real-time dashboards



\## Tech Stack



\### Backend

\- FastAPI (Python web framework)

\- PostgreSQL (database)

\- SQLAlchemy (ORM)

\- Pandas (data analysis)

\- Scikit-learn (ML algorithms)

\- Claude API (AI explanations)



\### Frontend

\- Next.js (React framework)

\- TypeScript

\- Tailwind CSS

\- Recharts (visualizations)
